# CHOI RIVER Galaxy widget
Native Android home screen widget, default 3×1. The launcher ultimately chooses cell sizes; resize horizontally/vertically by long-pressing the widget.

- Translucent pearl/blue background; native scrollable list.
- Pending academy lessons first (science/PT, class/clinic). Overdue pending academy rows remain until attendance is recorded.
- School tasks from today through Sunday in Asia/Seoul, only 시작전 / 진행 중 / 진행 2차 / 작성 완료.
- Click any row to open the existing main web dashboard. Browser login is separate from widget setup.
- Read-only Cloudflare /widget/feed API. Pair once with a 12-character, 5-minute code generated in the main dashboard notification settings. The app never receives the shared dashboard password or Notion token.
- Android Keystore AES-GCM encrypts the on-device read-only device token and cached schedules. Backup and cleartext traffic disabled.
- Android system refresh requested every 30 minutes; delivery may be delayed by battery/background restrictions. Manual ↻ requests a refresh job. This is a read-only widget, not a replacement for push notifications.
- Clinic counts are controlled by the existing Notion formulas/server. Widget never changes records.

## Install
GitHub Actions → Build CHOI RIVER Galaxy widget → latest successful run → artifact choi-river-widget-3x1 → unzip → install app-debug.apk on the Galaxy. Open CHOI RIVER 위젯, enter the **widget pairing code** from dashboard 알림 설정 → 홈 화면 위젯 연결, connect, then add the widget. A launcher widget chooser can also be used: long-press home screen → 위젯 → CHOI RIVER.
This first build is a debug-signed personal test APK. Signing identity is generated by the runner; later builds are not guaranteed to install as in-place updates. A production release needs a stable private signing key kept in repository secrets (never in git). If a future test APK has a different signing identity, uninstall/reinstall and reconnect it.

## Build
JDK 17, Gradle 8.9, Android SDK 35. In this directory: gradle :app:testDebugUnitTest :app:assembleDebug :app:lintDebug
The workflow uploads APK + test/lint reports; does not change the existing website or Cloudflare deployment.

## Read-only connection
Deploy the current river/server/worker.mjs to Cloudflare first (same RIVER_KV). Dashboard admin authentication generates a temporary pairing code. Pairing returns a distinct device token, whose hash and widget:read scope are stored in KV. It is accepted only by /widget/feed and /widget/disconnect; it cannot authenticate /tasks or /academy mutations. The feed omits completed lessons/tasks and unrelated Notion properties. Revoke devices from the dashboard. Pair codes are removed on redemption, but KV is eventually consistent: repeated redemption may briefly return the same device credential, never admin permissions. Tokens are not URL parameters or build secrets.
