1. 기본 추출 또는 AI 구조 정리를 선택하세요.
2. PDF·PPTX 파일을 올리고 변환을 누르세요.

기본 추출은 파일을 외부에 보내지 않습니다. AI 정리는 추출된 텍스트를 해당 AI 업체로 전송합니다. 스캔 PDF는 OCR을 먼저 거쳐야 합니다. AI 정리는 텍스트 기반이므로 이미지·도표 자체를 판독하지 않습니다.

AI 업체의 브라우저 직접 호출 정책이나 모델 접근 권한에 따라 API 호출이 실패할 수 있습니다. ChatGPT·Claude 앱 구독과 API 결제는 별개입니다.
