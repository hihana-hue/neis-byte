1. PDF·PPTX·HWPX 또는 JPG·PNG·WEBP 이미지를 올리세요.
2. 마크다운으로 변환을 누르세요.
3. 결과를 수정한 뒤 복사하거나 .md로 저장하세요.

문서와 이미지는 브라우저에서 처리하며 외부 서버로 전송하지 않습니다. API 키가 필요 없습니다. 이미지 OCR은 한글·영문을 인식하며 첫 실행 때 엔진·언어 자료를 내려받습니다.

텍스트가 없는 PDF 페이지는 자동으로 OCR 처리합니다. 이미지는 밝기를 보정하고 제목·목록을 정리합니다. 화면 메뉴는 위·아래 제외 비율로 빼세요. 사진에 없는 글자나 링크 주소를 만들어 넣지 않으며 그림 자체를 설명하지 않습니다. 복잡한 표·수식·손글씨·읽기 순서는 원문과 비교하세요. HWPX는 본문과 단순 표를 지원하며 병합된 셀과 배치는 달라질 수 있습니다. 구형 HWP와 암호화된 문서는 지원하지 않습니다.
