# 학생별 웹·위젯 연결
관리표: https://app.notion.com/p/400215b9b77480c89fd4c2befb161cef
학생에게 줄 공통 웹 주소: https://www.marihome.co.kr/river/

## 서버 적용
기존 Cloudflare Worker의 코드를 이 버전 worker.mjs로 교체하고 배포합니다.
기존 NOTION_TOKEN, RIVER_KV, ALLOWED_ORIGIN 설정을 유지합니다.
STUDENT_REGISTRY_ID는 생략하면 현재 위젯관리 데이터 원본을 사용합니다.
노션에서 위젯관리 DB 및 각 학생의 학교·학원 DB에 해당 Notion 연동의 접근 권한을 부여합니다.
관리표에 이름·중복되지 않는 연결코드·학교 DB 링크·선택 학원 DB 링크를 입력하고 연결 활성화를 체크합니다.
학생 DB는 현재 학교·학원 DB와 같은 속성 구조를 사용해야 합니다. 학원 DB가 비어 있으면 학원 목록은 비어 있습니다.
비공개 DB ID만 알아서는 연결할 수 없으며 연동 접근 권한과 등록·활성화된 연결코드가 필요합니다.

## 사용
웹에서 연결하기를 누르고 학생 연결코드를 입력합니다.
웹은 연결코드를 인증값으로 서버에 전달하므로 이 코드를 가진 사람은 해당 학생의 일정을 조회·수정할 수 있습니다.
코드는 URL에 넣지 않습니다. 로그인 유지를 선택한 기기에만 저장합니다.
위젯 1.20에서는 같은 코드를 입력하면 조회 전용 기기 토큰을 발급받습니다. 일회용 코드 생성은 필요 없습니다.
위젯 기기 토큰은 90일 유효하며 연결코드 변경 또는 연결 비활성화 시 다음 조회부터 거부됩니다.
현재 위젯 연결은 앱 단위로 저장되므로 한 휴대폰에서는 한 학생을 선택합니다.
위젯에서 웹을 열면 학생 식별자만 URL에 넣고, 웹에 다른 학생으로 로그인돼 있으면 해당 학생 코드 입력을 요구합니다.
기존 관리자 접근키와 예전 위젯 토큰은 이전 강이 DB용으로 호환합니다.
노션 관리표 등록만으로 현재 운영 중인 Worker가 자동 갱신되지는 않습니다. 새 Worker 배포가 필요합니다.
