# 개인 일정·학교 과목 표시 수정 — 내부 45 준비본

기준 소스: 5cd06a388731aa3cb7bb36cd3dc35d0e2add8bfc (내부 44)

- 학교 과목 색상 영역은 사각형 기반, 모서리 반경 4px(웹)/4dp(위젯). 기존 10dp는 낮은 라벨 높이에서 양옆이 캡슐처럼 보여 축소.
- 학원 등록 및 다음 수업 등록에서 제목 입력을 숨기고 과목명 + 수업/클리닉으로 저장. 서버도 학원 제목이 비어 있으면 자동 생성. 약속·교회·기타는 실제 일정명 필수 유지.
- 위젯 첫째 줄은 학원 과목명. 둘째 줄은 수업 · 회차 또는 클리닉. 과목명을 아래에 반복하지 않음. 별도 보강 제목은 둘째 줄에 보존. 날짜·시간은 기존 아래쪽 유지.
- 수업 회차·원비 필수 입력, 클리닉 회차 차감 제외, 개인 일정에 원비 항목 숨김 유지.
- 배포 시 기존 패키지·서명키로 45번 APK 제작. 공개 업데이트 정보는 실제 APK 생성 뒤 갱신해야 함.

검증: 서버 회귀 검사 전체, 웹 등록 상호작용(jsdom), Android XML 파싱 통과. Android JDK/SDK가 없어 APK 빌드·JUnit 실행은 미완료. 갤럭시 실기기 시각 검증 미완료.

상태: 사용자가 기존 저장소 업로드 및 배포를 승인함. 검사·동일 키 서명 후 호환 서버 배포, APK 공개 및 다운로드 정보 갱신을 수행하도록 워크플로 구성. 배포 완료 여부는 Actions 실행 결과로 확인할 것.
